# IfPlay

把一句游戏想法变成能在浏览器里玩的小游戏。

IfPlay 面向不会编程的普通用户和内容创作者。用户用中文描述题材、身份和玩法，系统生成网页小游戏，随后可以继续试玩和修改。

当前仓库用于开发 IfPlay 的作品集演示版。第一阶段基于 [OpenGame](https://github.com/leigest519/OpenGame) 改造，先把最短流程跑通，再逐步补充产品界面和稳定性能力。

> 项目刚刚建立，代码与试玩版本正在迁入。下方内容描述当前开发目标，不代表这些能力已经全部完成。

## 计划展示的体验

1. 输入一句中文游戏想法。
2. 确认玩法、目标和视觉方向。
3. 等待系统生成并检查网页游戏。
4. 直接在浏览器中完成一轮试玩。
5. 用自然语言提出修改并再次试玩。

第一版会优先做好一条可重复演示的完整流程，并准备两到三款稳定样例。账户、社区、支付和复杂运营功能暂不进入这一版。

## 本轮取舍

作品集版先证明用户能从一句想法走到一个可玩的结果。首版聚焦生成、试玩和修改，控制模型调用、图片数量和自动修复次数，避免外围功能拖慢演示版本。

涉及生成代码的步骤会保留构建、测试和错误记录。没有通过检查的结果不会标记为可玩版本。

## 项目来源

本项目参考并改造 [OpenGame](https://github.com/leigest519/OpenGame)。OpenGame 是一个从自然语言提示生成网页游戏的开源 Agent 框架，采用 Apache License 2.0。后续引入其代码时，将按许可证要求保留版权和许可声明，并单独记录第三方组件。

IfPlay 的产品定位、中文创作流程、展示界面和样例内容会在本仓库中继续开发。
