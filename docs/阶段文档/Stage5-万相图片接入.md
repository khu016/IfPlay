# Stage 5：万相图片接入

日期：2026-10-06

## 结论

阿里云百炼万相文生图已接入 IfPlay 本地环境，密钥有效，OpenGame 图片服务能够提交异步任务、轮询结果并下载 PNG。

## 配置

- Provider：`tongyi`
- Base URL：`https://dashscope.aliyuncs.com`
- MVP 模型：`wanx2.1-t2i-turbo`
- API Key：仅保存在本机 `.env`，不进入 Git 和文档

## 真实验证

### 万相 2.5 协议验证

- 模型：`wan2.5-t2i-preview`
- 尺寸：`1280*1280`
- 结果：成功
- 耗时：约 13 秒
- 输出：PNG，约 1.3 MB

### OpenGame 默认参数验证

- 模型：`wanx2.1-t2i-turbo`
- 尺寸：OpenGame 默认 `1024*1024`
- 结果：成功
- 耗时：约 11 秒
- 输出：PNG，约 0.86 MB

## 模型选择原因

OpenGame 0.6.0 默认请求 `1024*1024`，其素材类型也包含 `512*512`、`1536*1024` 等规格。万相 2.5 的当前尺寸约束与这些默认值冲突。为避免游戏生成过程中图片任务随机失败，MVP 暂时使用兼容现有尺寸协议的 `wanx2.1-t2i-turbo`。

如果后续升级到万相 2.5、2.6 或 2.7，需要先在图片适配层完成尺寸归一化和对应同步或异步协议适配，不能只替换模型名。

## 质量观察

测试图能命中雨夜城市、蓝紫色与扁平插画风格，但没有稳定表现提示词中的纸飞机。当前证据只能证明调用链路可用，不能证明图片提示词已经达到产品验收标准。

## 下一步

1. 在完整游戏生成中要求仅生成一张背景图，验证生成、下载、版本保存和试玩加载全链路。
2. 将本地图片、字体等资源纳入安全预览打包，禁止任意外链。
3. 记录每张图片的实际费用，并加入单项目 10 元成本上限。
4. 为背景、角色和道具分别建立提示词模板与命中率样本。
