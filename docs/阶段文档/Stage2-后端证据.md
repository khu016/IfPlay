## 接口清单

| 方法 | 地址 | 用途 |
| --- | --- | --- |
| GET | `/api/health` | 服务、生成模式和队列状态 |
| POST | `/api/projects` | 创建匿名项目 |
| GET | `/api/projects/:id` | 查询项目状态 |
| POST | `/api/projects/:id/generations` | 初次生成或继续修改 |
| GET | `/api/tasks/:id` | 查询真实任务状态 |
| GET | `/api/projects/:id/versions` | 查询最近版本 |
| GET | `/api/projects/:id/preview` | 获取当前试玩 HTML |

除健康检查和项目创建外，接口都要求 `x-project-token`。
