## 已完成体验

- 输入中文游戏想法，也可以点击三个示例快速开始。
- 创建匿名项目并显示生成前确认卡。

## 视觉与交互方向

- Workbench 工作台结构：左侧创作与修改，右侧试玩。
- Hum 主题：奶油色纸面、小面积梨黄、青色和珊瑚色，保持友好但不幼稚。
- 没有宣传型大标题、虚构指标、假浏览器框或同款三卡片布局。
- 所有交互具备键盘焦点、悬停、按下、禁用、加载、错误和成功反馈。
- 动画只用于页面首次进入、按钮反馈和功能性加载，并支持减少动态效果偏好。

## 浏览器实测

在本地页面 `http://127.0.0.1:8787` 完成以下真实操作：

1. 选择“深夜便利店”示例。
2. 创建项目并确认第一版。
3. 生成并加载 v1 试玩内容。
4. 输入“把提示文字改得更紧张一些，并保留点击玩法”。
5. 生成 v2，试玩内容同步显示新的修改要求。
6. 检查浏览器控制台，没有错误或警告。

响应式检查覆盖 320、375、414 和 768 像素宽度：

- 所有宽度均无横向滚动。
- 主要按钮没有换行。
- 手机端自动改为上下布局，创作区在前，试玩区在后。
- 试玩 iframe 在手机端保持可操作高度。
