# Stage 11：本机邀请测试准备

日期：2026-10-07  
当前结论：本机邀请测试基础设施通过；Stage 11 总门禁尚未完成。

## 已确认范围

Keiry 选择先采用本机邀请测试，不在本阶段等待供应商人民币账单，也不把云端沙箱作为本次开发的前置条件。账单不再阻塞后续工作，但已有成本目标仍保持“未核对”，不能改写成已经达标。

## 已完成

- 开启邀请码门禁后，没有有效测试资格不能创建新项目。
- 初始化 20 个一次性邀请码，每个邀请码最多创建 3 个项目；总测试席位硬限制为 20。
- 邀请码和后台凭证只保存哈希，明文仅写入 Git 忽略的 `.data/beta-access.json`。
- 游戏想法、策划回答、修改反馈和试玩记录进入本地内容筛查。
- 高置信危险请求直接拦截；外部链接、联系方式、定向仇恨或提示词覆盖等内容进入人工复核。
- 人工复核允许或拒绝后会保存结果；允许的相同内容可以原样重试。
- 可玩版本旁新增试玩结果表单，记录完成一轮、遇到阻断或中途退出、1–5 分评分、具体反馈和设备信息。
- 本机测试后台 `/beta` 展示邀请额度、已兑换资格、测试项目、完成记录和人工复核队列，并可新增未超过总席位上限的邀请码。
- `npm run beta:report` 可以在终端读取不含密钥的汇总。
