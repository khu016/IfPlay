# Stage 9：版本历史与恢复

更新时间：2026-10-07  
状态：完成

## 目标

让用户能够辨认当前版本、预览任一保留版本，并在不调用模型、不覆盖历史的前提下恢复旧版本。

## 已完成

1. 版本列表返回版本号、摘要、父版本、恢复来源、生成方式、测试记录状态、费用状态和当前标记。
2. 对外版本数据移除服务端文件路径和完整内部执行指令。
3. 任一保留版本可以通过独立接口预览，资源继续遵守试玩沙箱的路径与大小限制。
4. 恢复操作创建新的版本记录，旧版本和恢复前版本都保持不变。
5. 恢复直接复用已保存产物，不创建模型任务，费用固定记录为 0 元。
6. 页面提供版本记录、历史预览、返回当前版本和恢复入口。
7. 历史预览明确标注“当前版本没有改变”，避免把预览误认为恢复成功。

## 已知边界

- 当前真实项目只有一个保留版本，因此没有在该项目执行真实恢复；多版本预览与恢复由独立自动场景验证。
- 生成版本的人民币费用仍待供应商账单核对，界面只显示“费用待账单核对”。
- 手动固定版本和超过 10 个版本后的固定保留策略尚未进入本阶段。
